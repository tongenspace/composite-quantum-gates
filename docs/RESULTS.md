# Figures and tables: inputs and reproduction

Run commands from the repository root. All generated figures go to
`outputs/figures/`; published figures remain unchanged.

| Manuscript result | Input and calculation |
|---|---|
| Figures 1--5: constant-amplitude X landscapes | `data/controls.json`, `scripts/plot_constant.py` |
| Figure 6: variable-area X controls | `scripts/plot_variable.py` |
| Figures 7--8: variable-area Hadamard primitives | `scripts/plot_variable.py` |
| Figure 9: normalized area and central mean | `data/static_metrics.json`, `scripts/plot_resources.py` |
| Figure 10: connected 1e-4 boundaries | `scripts/plot_variable.py` |
| Figure 11: phase precision | `studies/phase_precision/phase_precision_data.json` and `scripts/plot_phase_cached.py` |
| Figure 12: edges, noise bandwidth, combined finite-domain means | `studies/edges_noise/edge_results.json`, `studies/edges_noise/plot_edges.py` |
| Repository-only design-methods table | `design/design_methods_table.tex`, `design/design_methods_table.pdf`, `design/METHODS.md` |
| Repository-only evaluation-grid convergence | `python reproduce.py grid-convergence`; figure and full results in `studies/grid_convergence/` |
| Tables I--II: performance comparisons | `python reproduce.py tables` |
| Tables III--IV: numerical control coefficients | `data/controls.json`, chronological amplitudes and phases/pi, rounded to five decimals |

`python reproduce.py figures` generates all twelve figures. It uses recorded
ensemble data for Figures 11--12. `python reproduce.py phase` and
`python reproduce.py edges` recalculate those data in separate output folders.

For Figure 12, panels (b) and (d) use identical 81x81 static-error grids.
The combined data are also tabulated in
`studies/edges_noise/combined_panel_data.csv`. Panel (c) is evaluated at zero
quasistatic error, not averaged over B_0.15.

The two table CSVs generated by `tables` contain the numerical values before
formatting to the manuscript's precision. The table script checks agreement
with the frozen metrics when using the publication grid size of 801.
